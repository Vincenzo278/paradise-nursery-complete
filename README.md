# Paradise Nursery
A responsive React houseplant shopping app using Redux Toolkit and React Router.

## Features
- Landing page and Get Started navigation
- 18 plants in three categories (six per category)
- Add-to-cart button disables after adding
- Live cart quantity, quantity controls, delete, and calculated totals
- Checkout placeholder and Continue Shopping navigation

## Run
```bash
npm install
npm run dev
```
